# 主流大模型一览（2026 年 10 月）

大模型（LLM，Large Language Model）是基于 Transformer 架构、在海量文本上
预训练的生成式模型。本文按「闭源 API / 开放权重」两大类梳理截至 2026 年
10 月的主流模型家族与选型要点。

> **时效声明**：大模型迭代以周为单位，本文信息来自公开报道的聚合检索，
> 截稿于 2026-10。具体版本号、跑分与价格请以各官方页面和榜单当日数据为准。

## 闭源商业模型（走 API）

- **OpenAI · GPT-5.5 / GPT-5.6**：GPT-5 系列的迭代版本，综合能力第一梯队，
  编程与 Agent（工具调用）任务表现突出；有报道称 GPT-5.5 在 Terminal 类
  任务上领先（约 82.7%，第三方口径）。
- **Anthropic · Claude Opus 5**：2026 年 8 月发布的旗舰。Artificial Analysis
  智能指数约 61 分（当时史上最高），长上下文推理与编程被普遍认为最强之一；
  同代还有更便宜更快的 Sonnet 档位。
- **Google · Gemini 3.x（Pro / Flash）**：多模态（文本 / 图像 / 音视频）能力
  口碑最好，Flash 档性价比高，8 月的 3.7 Flash 强化了 STEM。
- **xAI · Grok 4.x**：Grok 4.5（7 月）、4.6（8 月）等小步快跑；旗舰 Grok 5
  截至9 月仍未发布，传闻是约 6 万亿参数、在 Colossus 2 超算上训练，
  预计窗口一再跳票。

## 开放权重模型（可私有化部署）

2026 年的开放权重阵营由**中国团队主导**，多份生产环境统计显示
DeepSeek、Qwen、Kimi、GLM 是使用量最大的开源模型家族：

- **DeepSeek · V3.2 / V4**：性价比与成本效率的标杆，API 价格长期最低档，
  V4 延续「便宜大碗」路线；
- **阿里 · Qwen 3.x（通义千问）**：开源生态最完整的家族之一，尺寸从端侧
  小模型到 MoE 旗舰全覆盖，Qwen3-VL 系列带视觉能力（本项目网关用的就是
  Qwen3-VL-4B 的 AWQ 量化版，vLLM 本地部署）；
- **月之暗面 · Kimi K2.6 / K3**：长文本起家，K2/K3 在中文综合与 Agent
  任务上表现强；
- **智谱 · GLM 4.7 / GLM-5 系列**： benchmark 表现稳定的第一梯队开源模型，
  有 API 也有开放权重；
- **MiniMax · M3**：编程能力在多个横评里登顶开源阵营；
- **Meta · Llama 4（Scout / Maverick / Behemoth）**：西方开源的门面，但
  2026 年风头明显被中国模型压过；Llama 5 尚未发布；
- **Mistral · Large 3**：欧洲开源代表。

## 选型要点

1. **先分场景再选型**：编程 / 复杂推理看 Claude Opus 5、GPT-5.5、MiniMax M3；
   多模态看 Gemini；要便宜量大看 DeepSeek；要私有化部署看 Qwen、DeepSeek、
   GLM 的开放权重版。
2. **上下文长度**：各家旗舰普遍支持 128K~1M 级别，但长上下文的实际有效
   利用率各不相同，长文档任务要实测。
3. **API 与本地部署**：API 免运维、按 token 计费；开放权重模型用 vLLM 等
   推理框架自建（如本项目），量化（AWQ / GPTQ）后消费级显卡也能跑 4B~70B。
4. **榜单只作参考**：Artificial Analysis、LMArena 等聚合榜单用于缩小范围，
   最终以自己业务集上的实测为准。
